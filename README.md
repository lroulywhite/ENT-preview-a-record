# ENT | Preview a Record [Simulation]

Guided click-through simulation for Momentus Enterprise (Events list): select a record, show the Reading Pane, find the splitter bar, open the gear icon to see the grid options.

Built for the Learning Center and embedded in Genially.

## Publish with GitHub Pages
1. Create a repo named `ENT-preview-a-record` and upload `index.html` and `.nojekyll` (README is optional).
2. Settings > Pages > Deploy from a branch > `main` / root.
3. The live link will be `https://lroulywhite.github.io/ENT-preview-a-record/`.
4. In Genially, embed that link (iframe). Tell learners to open it in full-screen mode.

## Notes
- One self-contained file. No external requests. About 2.6 MB.
- Screens come from approved Enterprise captures (Events list). Product UI is not redrawn.
- The splitter step points out the bar but does not include dragging (no capture of a resized pane).
- Real-looking demo names were replaced with fictional ones.
